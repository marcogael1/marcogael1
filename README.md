- 🔭 Currently building **CRM / lead-management systems** with **Django**, featuring AI-powered data extraction, push notifications and Google Calendar sync

## 💼 Experience

### Backend Developer · [Freepi Inc.](https://github.com/Freepi-Inc)

**Freeleads — Lead management CRM**
- Building and maintaining the **Django** backend of a CRM for tracking leads, clients, quotes and events
- Redesigning the **automation rules engine**: a 3-step wizard (trigger → processing → output) that fires automatic actions such as messages, tags and status changes, extended beyond leads to quotes and events
- **AI-powered data extraction** with the Groq LLM API, handling model selection, input chunking and rate-limit mitigation

- **Google Calendar** sync for events
- Deployment on **AWS EC2** with Gunicorn, media storage on **S3** via django-storages
